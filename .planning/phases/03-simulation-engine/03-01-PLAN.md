**Module-level constants (include citation comments exactly as shown):**
```python
# Physical bounds for absolute temperature
TEMP_MIN_F = 0.0    # Absolute lower bound (°F)
TEMP_MAX_F = 150.0  # Absolute upper bound (°F)

# beta_canopy: 0.04°F cooling per 1% canopy increase
# Source: Seattle canopy research (technical_spec.md); +13% canopy → ~0.5°F cooling; 0.5/13 ≈ 0.04
BETA_CANOPY = 0.04

# beta_albedo: 5.4°F cooling per full albedo unit increase (0→1)
# Source: Mesoscale UHI modeling consensus (Scientific Reports 2024 PMC10766998; MDPI Buildings 2024);
# 0.3°C per 0.1 albedo unit × 10 × 1.8°F/°C = 5.4°F/unit.
# Range in literature: 0.09–0.61°C per 0.1 unit depending on climate and study design.
BETA_ALBEDO = 5.4

# beta_green_space: 5.0e-6 °F cooling per sqft of added green space
# Source: Manchester urban study (ScienceDirect 2025): +5% tree density across ~200 acre tract → -1.0°C;
# 5% × 8,712,000 sqft = 435,600 sqft → -1.8°F; coefficient = 1.8/435,600 ≈ 4.1e-6.
# Midpoint with Adama City study (Tandfonline 2024): 5.5 ha → -2.85°C → ~8.6e-6.
# Conservative midpoint adopted: 5.0e-6. Note: per-sqft linearity is a planning simplification.
BETA_GREEN_SPACE = 5.0e-6

# heat_weight: heat's contribution to overall risk score (technical_spec.md)
# risk = 0.4×heat + 0.3×canopy_gap + 0.2×health + 0.1×equity
HEAT_WEIGHT = 0.4

# NULL fallback for mean_afternoon_temp when DuckDB returns None
TEMP_NULL_FALLBACK_F = 85.0
```

**Imports:** import duckdb; from fastapi import HTTPException; from app.schemas.simulations import Interventions, WhatIfResult, CompareResult, ScenarioDelta

**Private function _compute_simulation(db, tract_ids, interventions) -> list[dict]:**
- Use db.cursor() (never db.execute directly — thread safety)
- Single IN-clause query with parameterized placeholders joining tract_features + tract_outputs_with_preds:
  SELECT tf.tract_id, tf.mean_afternoon_temp, top.xgb_heat_score, top.xgb_risk_score
  FROM tract_features tf JOIN tract_outputs_with_preds top ON tf.tract_id = top.tract_id
  WHERE tf.tract_id IN ({placeholders}) ORDER BY tf.tract_id
- After fetchall(), build found_ids = {row[0] for row in rows}, then iterate tract_ids to find any missing — raise HTTPException(status_code=404, detail=f"Tract '{tid}' not found") on first missing ID (check BEFORE formula application)
- For each row, apply formulas:
  1. raw_delta = -(BETA_CANOPY*(interventions.tree_canopy_pct or 0.0) + BETA_ALBEDO*(interventions.albedo_delta or 0.0) + BETA_GREEN_SPACE*(interventions.green_space_sqft or 0.0))
  2. base_temp_safe = mean_afternoon_temp if mean_afternoon_temp is not None else TEMP_NULL_FALLBACK_F
  3. simulated_temp = max(TEMP_MIN_F, min(TEMP_MAX_F, base_temp_safe + raw_delta))
  4. bounded_delta_temp = simulated_temp - base_temp_safe
  5. delta_risk = HEAT_WEIGHT * xgb_heat_score * (bounded_delta_temp / base_temp_safe)
  6. simulated_risk = max(0.0, min(1.0, xgb_risk_score + delta_risk))
  7. bounded_delta_risk = simulated_risk - xgb_risk_score
- Return list of {"tract_id": ..., "delta_temp": round(bounded_delta_temp, 4), "delta_risk": round(bounded_delta_risk, 4)}
- DO NOT call app.state.models — models are forbidden in the simulation service (v1 parametric only)

**Public function simulate_what_if(db, tract_ids, interventions) -> list[dict]:**
- Directly return _compute_simulation(db, tract_ids, interventions)

**Public function simulate_compare(db, tract_ids, scenario_a, scenario_b) -> list[dict]:**
- Pre-validate: call _compute_simulation once for scenario_a only to check all tract IDs exist and are valid — if any 404 is raised, it propagates immediately (avoids checking twice for different unknown IDs)
- Actually: call _compute_simulation for both scenarios:
  results_a = {r["tract_id"]: r for r in _compute_simulation(db, tract_ids, scenario_a)}
  results_b = {r["tract_id"]: r for r in _compute_simulation(db, tract_ids, scenario_b)}
- Merge by tract_id key (not by position — ORDER BY tf.tract_id in query ensures deterministic order but key-based merge is safer):
  return [{"tract_id": tid, "scenario_a": {"delta_temp": results_a[tid]["delta_temp"], "delta_risk": results_a[tid]["delta_risk"]}, "scenario_b": {"delta_temp": results_b[tid]["delta_temp"], "delta_risk": results_b[tid]["delta_risk"]}} for tid in sorted(results_a.keys())]
